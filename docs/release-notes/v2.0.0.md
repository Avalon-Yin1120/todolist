# 待办提醒 2.0.0

**正式版。从 1.0.0 原地升级，待办与设置原样保留。**

- 包名与 1.0.0 相同（`com.avalonyin1120.todolist`）、同一把签名、`versionCode 2`（1.0.0 是 1）
- 装法：**直接覆盖安装**（不要先卸载，卸载会清数据）
- 支持 Android 8.0（API 26）及以上；没有 `INTERNET` 权限，数据只在本机

## 这一版相对 1.0.0 新增了什么

**提醒**
- 三种提醒方式：通知 / 闹钟式（到点响铃 + 亮屏 + 全屏提醒页）/ 不通知
- 周期待办按场次完成：日常规则里某一天做完不影响其他天
- 「提前提醒」可自定义任意分钟数（0–10080），常用值可钉成快捷按钮
- 提醒可靠性检查：按 OPPO / 小米 / vivo 等厂商给出逐项设置路径，读不到的状态交给你确认

**视图**
- 日 / 周 / 月三种日历视图，左右滑动翻页
- 周视图是时间轴，重叠的待办自动分泳道
- 月视图：每天右上角显示件数角标 + 底部横条按总时长变长变深
- 任意视图都能「跳转到指定日期」

**输入**
- 「一句话新建」：`明天下午三点开会，提前 20 分钟` 自动填好日期、时间、时长、重复与提前量
- 时间区间写法：`3点到5点`、`下午三点到五点`、`15:00-17:00`、
  `明天早上五点到下午六点`（两端各带时段词）、`晚上十一点到凌晨一点`（跨夜）

**个性化**
- 卡片按状态 / 按提醒方式 / 统一颜色三种上色依据，12 色可选；「已完成」单独配色
- 「颜色」与「快捷按钮」两个标签页

**记录**
- 事件日志（新增 / 修改 / 删除 / 完成 / 排定 / 触发 / 响铃 / 停止…），保留 7 天、上限 800 条
- 「导出（名称脱敏）」把待办名换成 `〈待办#3：5 字〉`，方便把日志发给别人排查

## 升级须知

1. **不要卸载旧版再装**：`1.0.0` 的数据在应用私有目录里，卸载即清除。直接覆盖安装即可。
2. 升级后提醒会按库里的数据自动重排一次，不需要重新设置。
3. 开发期的预览包（应用名带「·预览」、包名带 `.preview`）是**另一个应用**，它的数据不会迁移过来；
   升级后可以单独卸载它。

## 校验

- 文件名：`todolist-2.0.0.apk`
- SHA-256 见同一 Release 的 `SHA256SUMS.txt`
- 签名证书 SHA-256：`3226b61f6503d52b0c5b9ef1b50e88e3952190a783674f61caf3027465b333a6`
  （`apksigner verify --print-certs 你的.apk` 可自行核对，不一致就别装）

## 已知限制

- 后台提醒依赖系统省电策略：OPPO / 小米等厂商需手动开「允许完全后台行为 / 自启动」，
  应用内「提醒可靠性检查」会带你逐项开。
- Android 14+ 可能撤销 `USE_FULL_SCREEN_INTENT`；未授予时闹钟式提醒退化为高优先级通知。
- 「强行停止」应用后系统不再投递广播，直到你重新打开一次应用。
